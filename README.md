📝 게임 방법 (설명창에 들어갈 내용)

[게임 방법]

시작: 'START' 버튼을 누르면 공이 아래로 떨어지며 게임이 시작됩니다.

속도감: 동시에 하단에서 벽돌(장애물)들이 빠른 속도로 솟구쳐 올라옵니다.

색상 변신 (핵심): 화면의 버튼을 터치하여, 다가오는 장애물에 맞춰 공의 색상을 즉각적으로 변경하세요!

목표: 알맞은 색상으로 변신해 장애물을 돌파하며 가장 깊은 곳까지 내려가 'TOP 5 랭킹'에 당신의 기록을 남겨보세요.
